# Historical content notice

The current release data is based on manuscript images from BnF Persan 348 and Smithsonian FSC-MS-28. It does not contain the earlier Wikisource-derived structural sample in the current file tree.

The public Git history nevertheless retains an initial, subsequently deleted file named `data/tei/mantiq-sample.xml` in commit `358a467`. That file was an experimental TEI structural transcription derived from the Persian Wikisource page *Manṭiq al-ṭayr/Āghāz*, accessed on 13 October 2026. It was not treated as an independent manuscript witness or a critical text and was removed from the release tree in commit `e807038`.

- The Wikisource page footer makes its text available under the Creative Commons Attribution-ShareAlike License. The historical derived sample must therefore be treated under CC BY-SA 4.0 rather than the current project’s CC BY 4.0 data licence.

Two deleted planning documents, `outputs/job-application-achievement-ja.md` and `outputs/publication-decisions-ja.md`, also remain retrievable from the initial public commit. They contain project planning text and already-public author identifiers, but no credentials or private third-party data. They are not release deliverables and should not be cited as current project documentation.

The Git history has not been rewritten because no secret or sensitive personal data was found, and rewriting would invalidate published commit references and release ancestry. This notice records the provenance and licensing boundary explicitly.
