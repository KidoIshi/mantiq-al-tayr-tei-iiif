# Persan 348・FSC-MS-28：TEI半句とIIIF画像領域の対応設計

作成日：2026年11月9日  
更新日：2026年11月12日
状態：Persan 348の30対句・60半句とFSC-MS-28の9対句・18半句、計3 Canvasについて技術実装・研究者確認済み

## 対応モデル

1. TEIの各半句`l`が`@facs`で`zone`を参照する。
2. `zone`は各IIIF Canvasと同じ座標系で、左上`ulx,uly`と右下`lrx,lry`を記録する。
3. 閲覧画面が座標を`x,y,w,h`へ変換する。
4. IIIF Image APIの領域URLを生成し、選択した半句の画像だけを表示する。

```xml
<zone xml:id="bnf348.f6.z001a"
      ulx="2350" uly="1310" lrx="2870" lry="1490"/>

<l xml:id="mt.bnf348.0001.a"
   facs="#bnf348.f6.z001a">آفرین جان آفرین پاک را</l>
```

上の座標から、領域`2350,1310,520,180`を生成する。

## 採用理由

- TEI本文と画像座標を分離し、同じ`zone`を閲覧、注釈、検証に再利用できる。
- 本文の識別子と画像領域の識別子を明示的に追跡できる。
- IIIF Image APIの領域取得を使うため、写本画像をリポジトリへ複製する必要がない。
- 将来、IIIF Presentation APIのCanvas上のWeb Annotationへ変換できる。

## 検証規則

Schematronで次を検査する。

- すべての半句が`@facs`を持つ。
- `@facs`が実在する`zone`を参照する。
- `zone`の幅と高さが正である。
- `zone`が対応する`surface`の幅・高さの範囲内にある。

## AIと研究者の境界

AIに委任できる作業：

- 行領域の初期座標推定。
- TEIの参照整合性検査。
- IIIF領域URLの生成。
- クリック・キーボード操作による画像切替の実装。
- 全座標が画像範囲内にあるかの機械検査。

研究者が判断する作業：

- 領域が対象半句を過不足なく含むか。
- 装飾、欄外、後補、行間書き込みを領域に含めるか。
- 一つの半句が複数領域にまたがる場合の分割方針。
- 画像領域を学術的引用単位として公開してよいか。
