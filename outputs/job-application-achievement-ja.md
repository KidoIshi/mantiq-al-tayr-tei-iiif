# 公募書類用 研究実績記述案

作成日：2026年11月10日  
使用時の注意：公開前は「公開した」と記載せず、「構築した」「実装した」「試作した」とする。

## 1. 研究実績欄向け短文

ペルシア語古典文学『鳥の言葉』のBnF Persan 348を対象に、TEI P5準拠の写本転写データとIIIF画像領域を接続するデジタル写本資料の試作を構築した。

## 2. 研究実績欄向け標準文

ファリードゥッディーン・アッタール『鳥の言葉』の写本BnF Persan 348を対象に、研究者確認済みの9対句・18半句をTEI P5で構造化した。外交的転写と検索用正規化を区別し、全半句をIIIF Canvas上の画像領域へ対応付けた。さらにTEIからIIIF Presentation API 3準拠のWeb Annotationを自動生成し、XML、TEI Relax NG、独自Schematron、TEI–IIIF間の本文・座標一致を検証する再現可能なワークフローと閲覧デモを実装した。

## 3. 業績説明・研究概要向け長文

ペルシア語古典文学資料の協働利用と再検証を可能にするため、ファリードゥッディーン・アッタール『鳥の言葉』のBnF所蔵写本Persan 348を対象とするTEI・IIIF統合試作を構築した。写本画像をもとに研究者が確認した9対句・18半句を、対句と半句の階層、安定識別子、責任表示、編集履歴を備えたTEI P5データとして記述した。写本どおりの外交的転写と検索・比較用正規化を`choice/orig/reg`で区別し、各半句をTEI `surface/zone`と`@facs`によりIIIF画像領域へ対応付けた。承認済みデータからIIIF Presentation API 3のAnnotationPageを自動生成し、公式TEIスキーマ、独自Schematron、TEIとIIIF注釈間の本文・座標一致を機械検証する処理を実装した。AIは仕様調査、候補生成、反復変換、検証、画面実装に利用し、本文判読、正規化方針、画像領域の承認は研究者が担う分業モデルを明示した。本成果は批判校訂版の完成を主張するものではなく、複数写本比較、翻訳対応、物語構造記述へ拡張可能な検証済み小規模基盤である。
