# 外部AI相互コードレビュー依頼文

## 目的

公開予定の *Manṭiq al-ṭayr* TEI–IIIFプロジェクトを、変更を加えずに第三者視点で監査してください。これは批判校訂版ではなく、二写本によるTEI・IIIF実装試作です。研究上の読みを新たに推測せず、コード、規格運用、再現性、公開上の表示の整合性を中心に確認してください。

対象リポジトリ：`https://github.com/KidoIshi/mantiq-al-tayr-tei-iiif`

レビュー時には、必ずレビュー対象のコミットSHAまたはタグを冒頭に記録してください。`main`のような可変参照だけでレビュー済み範囲を示さないでください。

## 実行してほしい確認

1. `python -m pip install -r requirements.txt`
2. `python scripts/verify_all.py`
3. `python scripts/check_release_readiness.py`
4. `git diff --exit-code -- schema/mantiq.rng iiif/`（実行時刻を含まない決定的生成物が変化しないか確認。`outputs/`の検証報告は実行時刻が更新されるため、この比較から除外する）
5. TEI XML、ODD、生成Relax NG、Schematronの役割分担を確認
6. TEIの`surface/zone/@facs`とIIIF AnnotationPageのCanvas・`xywh`・本文が一致するか確認
7. `app/rdg/@wit`の証人別抽出、`unclear`、`gap`、`choice/orig/reg`の処理を確認
8. 閲覧画面で、HTML注入、外部リソース、リンク安全性、エラー処理、アクセシビリティ上の明白な問題を確認
9. README、CITATION.cff、ライセンス、権利表示、件数、実装済み／未実装の主張が実データと一致するか確認
10. ローカル絶対パス、認証情報、内部作業資料、第三者画像ファイルが公開候補へ混入していないか確認

## 特に疑ってほしい点

- 「TEIに適合」と「学術的に正しい読み」を混同していないか。
- 静的な文字列検査を、実ブラウザ操作テストとして表現していないか。
- TEIや変換ツールのバージョンが固定され、取得物のチェックサムが検証されるか。
- 生成物が元データから再生成でき、手修正されたJSONとの不一致を検出できるか。
- 「二写本試作」を「批判校訂版」と過大表示していないか。
- AI支援と研究者判断の責任範囲が、実際の履歴と矛盾しないか。

## 報告形式

各指摘を次の形式で返してください。

- 重要度：Blocker / High / Medium / Low / Note
- 場所：ファイル名と行番号
- 観察した事実
- 影響
- 再現手順または根拠
- 最小修正案
- 学術判断が必要か：Yes / No

問題がない項目も「確認済み」として列挙してください。推測だけの指摘は推測と明記し、写本の読みに関する変更案は提示しないでください。

## 依頼者が外部AIの報告を受け取った後に行うこと

報告全文、レビュー対象SHA、実行環境、実行したコマンドを保存し、本プロジェクト側のレビュー記録と突き合わせます。修正採否は、技術的指摘は再現試験、学術的指摘は研究者判断によって決めます。
