# v0.3.3 — Clickable Zenodo link to the live demonstrator

Zenodo archive: https://doi.org/10.5281/zenodo.24202784

Version 0.3.3 adds `.zenodo.json` metadata so that Zenodo displays the public TEI–IIIF viewer as a clickable related resource:

https://kidoishi.github.io/mantiq-al-tayr-tei-iiif/viewer/

The same viewer link remains available near the top of the Japanese and English README files and in `CITATION.cff`.

No Persian transcription, collation result, TEI–IIIF image region, schema, transformation, or validation rule has changed since v0.3.2.

The project remains a technical and methodological prototype, not a critical edition. External manuscript images are referenced through the holding institutions’ IIIF services and are not included in the repository or Zenodo archive.
