# 『鳥の言葉』TEI・IIIF試作：編集判断ログ

更新日：2026年11月10日
状態：基本方針承認済み（写本を主資料、刊本を任意の比較資料とする）

## 1. このプロジェクトの目的

最終目的は、TEI・IIIFを使った画面を作ること自体ではない。AIに変換・実装・検査を委任しながら、研究者本人が次の事項を説明・判断できる能力と、その能力を裏づける再現可能な研究成果を作ることである。

1. ペルシア語韻文と物語構造を、なぜそのTEI要素で記述したか。
2. 本文、翻訳、話者、異読、写本画像を、どの識別子で結びつけたか。
3. TEI公式スキーマと独自Schematronが、それぞれ何を検査するか。
4. IIIF Manifest、Canvas、Image API、画像領域が、それぞれ何を表すか。
5. AIが生成した結果を、どの根拠と手順で検証したか。
6. 実装済み、研究者確認済み、未検証の範囲を明確に区別できるか。

公募で示す成果は、TEI XMLだけでなく、設計判断、検証レポート、IIIF連携デモ、再現手順、権利情報、技術説明を含む一式とする。

- Ganjoor: <https://ganjoor.net/attar/manteghotteyr/touhid/sh1>

Ganjoorの当該ページは一次ソースをWikisourceと表示している。このため、WikisourceとGanjoorは独立した二写本・二校訂版として扱わない。両電子テキスト間の文字列差も、写本で確認するまでは`<app>`・`<rdg>`による異読として符号化しない。

## 3. 採用する暫定方針

| 項目 | 暫定方針 | 理由 |
|---|---|---|
| 試作範囲 | 現在の冒頭25対句を維持 | 25対句という短期目標を満たし、既存検証を継続できる |
| 現在のテキスト | `reference transcription`として保持 | 出典は追跡できるが、写本照合済み本文ではない |
| 本番用底本 | 研究者が指定する校訂版または写本転記を待つ | 校訂方針は研究上の判断であり、AIが代行できない |
| 電子テキスト間の差 | 比較メモとして記録し、校異装置に入れない | 独立した写本証言ではない |
| 日本語訳 | 研究者の既存訳または承認済み訳のみ収録 | AI訳を研究成果上の確定訳にしない |
| IIIF画像 | 現状は並置表示のみ | Smithsonian画像と25対句の葉・行対応が未確認 |
| `@facs` | 対応葉を人間が確認するまで付与しない | 技術的リンクと学術的同定を区別する |

## 4. 本番用底本の選定条件

候補は次の条件で評価する。

1. 書誌事項と版が一意に特定できる。
2. 使用する25対句のページ・対句番号を示せる。
3. 転記または引用の利用条件を説明できる。
4. 研究者が本文の採否と正書法を確認できる。
5. 写本の場合は所蔵機関、請求記号、葉番号を記録できる。
6. 異読を扱う場合は、各読みがどの証人に基づくかを示せる。

## 5. 研究者が確定する事項

次の5点が確定すれば、AI側で本文置換、翻訳リンク、校異装置、検証規則、画面表示を一括更新できる。

1. 使用する版・写本の書誌情報。
2. 対象とする20〜30対句の範囲。
3. ペルシア語正書法を原綴のまま保持するか、検索用正規形を併記するか。
4. 使用可能な日本語訳の有無。
5. 該当写本画像の葉番号または同定候補。

## 6. 次工程の完了条件

- 研究者承認済み本文へ25対句を置換または照合する。
- 各対句に底本上の参照位置を記録する。
- 差異があれば「転記誤り」「版の差」「写本異読」を区別する。
- XML、TEI Relax NG、Schematronの全検証を再実行する。
- 変更前後と判断理由を`revisionDesc`および本ログに残す。

底本が未確定の間も、現在のデータは技術試作として有効である。ただし、公募書類では「批判校訂版を完成」とせず、「TEI P5準拠の構造化試料と検証・IIIF連携基盤を実装」と記述する。

## 7. ODD設計の承認

2026年11月10日、研究者は次のODD設計方針を承認した。

1. 独立した写本証拠による校異を今後実装する予定があるため、現時点で本文に`app`・`lem`・`rdg`がなくても、ODDに`textcrit`モジュールを含める。
2. 初版ODDは必要なモジュールを選択する方式とし、現在の30対句だけに要素集合を過剰適合させない。
3. 20〜30対句への拡張後、実際に使用した要素を確認し、要素単位のさらなる縮小を検討する。

これは「未使用要素を無制限に許可する」という判断ではなく、近接する研究計画を支えられる範囲を先に確保し、実データに基づいて段階的に制約を強める方針である。

2026年11月11日、scan f7を追加した際、各`surface`とIIIF Canvasの対応を`surface/@corresp`で明示するため、ODDへ`linking`モジュールを追加した。これは複数Canvasの機械変換に必要であり、将来予定する原文・翻訳の`linkGrp`対応にも再利用できる。専用ODDが当初`@corresp`を拒否したことで、必要な語彙拡張を明示的な設計変更として記録できた。
