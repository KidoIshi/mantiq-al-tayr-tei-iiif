# v0.3.2 — Direct link to the live demonstrator

Zenodo archive: https://doi.org/10.5281/zenodo.24202704

Version 0.3.2 adds a direct public link from the citation metadata and repository documentation to the TEI–IIIF viewer:

https://kidoishi.github.io/mantiq-al-tayr-tei-iiif/viewer/

The release also uses the Zenodo concept DOI in the archived README so that the citation link remains valid across later versions.

No Persian transcription, collation result, TEI–IIIF image region, schema, transformation, or validation rule has changed since v0.3.1.

The project remains a technical and methodological prototype, not a critical edition. The manuscript images are loaded from the holding institutions’ IIIF services and are not included in the repository or Zenodo archive.
